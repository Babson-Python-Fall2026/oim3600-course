OIM 3600 — Computer Setup Instructions

Fall 2026  ·  Babson College  ·  Complete all steps before the first class

⚠ Read This Before You Start
  • Follow every step in the exact order shown — do not skip ahead
  • Your GitHub username must be all lowercase in this format: firstname-fall2026 (example: alex-fall2026)
  • Use your Babson email address for everything
  • If you already have a GitHub account, you must create a new one for this class
  • If you get stuck at any step, email your instructor before class — do not wait
🏠 Do These Steps Before the First Class
1
Create Your GitHub Account

You need a GitHub account specifically for this class. Do this first — before anything else.

  1. Go to https://github.com/join in your browser
  2. For Username: use your first name followed by -fall2026 — all lowercase, no spaces
    Example: if your name is Alex Smith, your username is alex-fall2026
  3. For Email address: use your Babson email (example: asmith26@babson.edu)
  4. For Password: choose a strong password and write it down somewhere safe
  5. Complete any verification puzzle GitHub shows you and click Create account
  6. GitHub will send a verification code to your Babson email — find the code and enter it on the GitHub page
🚨 The username format must be exact: all lowercase, first name only, hyphen, then -fall2026. Examples: alex-fall2026, maria-fall2026, james-fall2026. Do not use your last name, initials, numbers, or dots.
✅ Once your account is created, email your instructor with your GitHub username, full name, and Babson email address. Your instructor needs this to add you to the course.
2
Create the PythonClass Folder
  1. Press the Windows key on your keyboard (bottom-left, looks like a flag)
  2. Type File Explorer and press Enter
  3. In the left panel, click This PC
  4. Double-click Local Disk (C:) to open the C: drive
  5. Right-click on any empty white space in the folder area
  6. Click New → Folder
  7. Type exactly: PythonClass — then press Enter
🚨 The folder name must be typed exactly as shown: capital P, lowercase ython, capital C, lowercase lass. Do not add spaces or use all lowercase. The full path must be C:\PythonClass
3
Download the Setup Files from Canvas
  1. Log into Canvas at canvas.babson.edu
  2. Open the OIM 3600 course
  3. Click Files in the left menu
  4. Find the file named PythonClass-Setup.zip and download it
  5. When the download appears in your browser, click the folder icon or Show in folder to find it — it will be in your Downloads folder
ℹ Do not open the zip yet — you must unblock it first (Step 4).
4
Unblock the Zip File, Then Extract

Windows automatically blocks files downloaded from the internet. You must unblock the zip before extracting it — this is the easiest way to ensure all extracted files are trusted.

  1. Open File Explorer and navigate to your Downloads folder
  2. Right-click on PythonClass-Setup.zip → click Properties
  3. At the very bottom of the Properties window you will see:
    "This file came from another computer..." with a checkbox labeled Unblock
  4. Check the Unblock box so a checkmark appears
  5. Click Apply then click OK
  6. Now right-click the zip again → click Extract All...
  7. In the dialog, type C:\PythonClass as the destination folder
  8. Click Extract
✅ Because you unblocked the zip first, all extracted files are automatically unblocked. You do not need to unblock each file individually.
⚠ If you do not see the Unblock checkbox, the file is already unblocked — this is fine, continue to Step 5.
5
Run Phase 1 — Install Software (as Administrator)
🚨 This step must be run as Administrator. If you are on a school-managed computer and cannot run as Administrator, contact Babson IT Services or email your instructor before proceeding.
  1. Press the Windows key
  2. Type Windows PowerShell — do not press Enter yet
  3. In the search results, right-click on Windows PowerShell
  4. Click Run as Administrator
  5. A window will pop up asking "Do you want to allow this app to make changes?" — click Yes
  6. A blue PowerShell window will open. Type the following command and press Enter: 
    cd C:\PythonClass
  7. Type the following command and press Enter: 
    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
  8. Type the following command and press Enter: 
    .\setup50.ps1
  9. The script will now install software. This may take 10–20 minutes. Do not close the window.
  10. When you see PHASE 1 COMPLETE on the screen, close this PowerShell window.
  11. Restart your computer before continuing to Step 6. This ensures all installed software is available.
⚠ Do not close the window while software is installing. If the window closes on its own with an error, take a screenshot and email your instructor.
6
Run Phase 2 — Configure Your Environment
ℹ This step uses PowerShell 7 (different from Step 5). Do not run as Administrator this time — open it as a normal user.
  1. Press the Windows key
  2. Type pwsh (not PowerShell — type exactly: pwsh) and press Enter
  3. A dark blue PowerShell 7 window will open. Type this command and press Enter: 
    cd C:\PythonClass
  4. Type this command and press Enter: 
    .\setup50.ps1
  5. The script will ask: "Enter your first name (letters only)"
    Type only your first name in all lowercase letters — no capital letters, no spaces, no numbers, no dots
    Example: if your name is Alex, type alex and press Enter
  6. The script will show your GitHub username in a green box — confirm it matches the username you created in Step 1
  7. A browser window will open asking you to sign into GitHub — sign in with the account you created in Step 1
  8. Click Authorize if prompted
  9. Come back to PowerShell — the script will continue installing VS Code extensions. Do not close the window.
  10. When you see PHASE 2 COMPLETE, the setup is done
✅ Phase 2 complete — stop here. The remaining steps will be completed during the first class session.
🏫 Complete These Steps During the First Class
7
Accept the GitHub Organization Invitation

Your instructor will add you to the course GitHub organization before class. You will receive an email invitation from GitHub.

  1. Check your Babson email for an invitation from GitHub to join Babson-Python-Fall2026
  2. Click the Accept invitation button in the email — this will open GitHub in your browser
  3. Click Join Babson-Python-Fall2026 to confirm
ℹ If you already accepted the invitation email before class, you can skip this step.
8
Accept the Course Assignment

This command creates your personal private copy of the course repository.

  1. Open a PowerShell 7 window (press Start, type pwsh, press Enter)
  2. Type the following command and press Enter: 
    gh student accept Babson-Python-Fall2026 oim3600 intro
  3. When it finishes, it will print a git clone command — you do not need to run that command; sync50.ps1 handles this for you
🚨 If you see an error saying "no membership found", you have not accepted the org invitation yet. Complete Step 7 first, then try this command again.
9
Open VS Code and Run sync50.ps1
  1. Look on your Desktop for a shortcut named OIM3600
  2. Double-click the OIM3600 shortcut — this opens Visual Studio Code
  3. In VS Code, open the Terminal by clicking the View menu at the top → click Terminal
  4. A terminal panel will open at the bottom of the screen. Type the following commands and press Enter after each: 
    cd C:\PythonClass
.\sync50.ps1
  5. The script will download your course materials — this may take 1–2 minutes
  6. When you see Sync complete, you are done
⚠ Make sure to cd C:\PythonClass first before running .\sync50.ps1 — the script must be run from the C:\PythonClass folder.
10
Verify Everything is Working

After sync50.ps1 completes, look at the left panel in VS Code. You should see these folders:

📁 classes
   📁 08-31M
   📁 09-02W
   📁 09-07M
   ... (and so on through December)
📁 labs
   📁 lab_01
   📁 lab_02
   📁 lab_03
   📁 lab_04
📁 sandbox
✅ You're all set! Setup is complete. From now on, at the start of every class session, simply double-click the OIM3600 shortcut on your desktop and run .\sync50.ps1 from C:\PythonClass in the terminal to get the latest course materials.

You can also run the validation script at any time to confirm your environment is healthy:

cd C:\PythonClass

🛠 Common Problems & Solutions

❓ "I already have a GitHub account"
You must create a new GitHub account specifically for this class using your Babson email and the username format firstname-fall2026. Your personal GitHub account cannot be used.
❓ "My first name has a number or special character in it"
Use only the letters of your first name. Remove any numbers, dots, or symbols. For example: j0hn → type john. If your name uses non-English characters, use the closest English letter equivalent.
❓ "I forgot to unblock the zip before extracting"
No problem — the setup script (setup50.ps1) automatically unblocks all files in C:\PythonClass as its first action. As long as you can run the script at all, the unblocking will be handled for you.
❓ "gh student accept says no membership found"
You need to accept the GitHub organization invitation before running this command. Check your Babson email for an invitation from GitHub to join Babson-Python-Fall2026 and click Accept. Then try the command again.
❓ "gh student accept says the classroom or assignment is not found"
Wait 2–3 minutes and try again. If it still fails, email your instructor with the full error message.
❓ "sync50.ps1 says I don't have access or permission denied"
You likely haven't completed Step 8 yet. Run gh student accept Babson-Python-Fall2026 oim3600 intro in PowerShell, then try sync50.ps1 again.
❓ "I can't run as Administrator in Step 5"
Your computer may be managed by Babson IT. Contact Babson IT Services or email your instructor before the first class.
❓ "The OIM3600 shortcut is not on my Desktop"
Phase 2 did not complete successfully. Close all windows and re-run Phase 2 from Step 6. Make sure you used pwsh (PowerShell 7) and not Windows PowerShell 5.
❓ "I see an error when running .\setup50.ps1"
Make sure you unblocked the zip before extracting (Step 4). Also make sure you ran the Set-ExecutionPolicy command in Step 5 before running .\setup50.ps1. If the error persists, take a screenshot and email your instructor.
